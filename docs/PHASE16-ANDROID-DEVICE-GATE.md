# المرحلة 16 (G): بوّابةُ أندرويد على الجهاز — CivilDraft 1.2.0

كلُّ ما يُقاس بلا هاتفٍ قِيس (السويت، Chromium بمحاكاة Capacitor، javac). ما بقي
**لا يُقاس إلا على هاتفٍ حقيقيّ**: اللمس، واتساب، الاهتزاز، الكيبورد، والتوقيع.
القرار: **Go** إن مرّت البنود ★ كلُّها. غيرُ ذلك: **No-Go** وأرسل ما فشل.

## ١ · البناء (مرّةً واحدة)
1. ارفع المشروع إلى مستودع GitHub (الفرع `main`).
2. Settings ← Actions ← General ← Workflow permissions ← **Read and write**.
3. المفتاح: `bash scripts/make-keystore.sh --gh` (أو `.ps1` على ويندوز). انظر `docs/ANDROID.md`.
4. Actions ← **Android APK** ← Run workflow. بعد ~10 دقائق: Releases ← `CivilDraft-N.apk`.
5. في سجلّ الخطوة «Build signed APK + AAB» سطرُ `SHA-256` — احفظه: كلُّ إصدارٍ قادمٍ يجب أن يطابقه.

إن فشل البناء: افتح الخطوةَ الحمراء وأرسل آخرَ ~40 سطراً منها.

## ٣ · ما ترسله عند الفشل
- رقمُ البند، وصورةُ شاشة.
- اسمُ الهاتف وإصدارُ أندرويد.
- إن أمكن، السجلّ: وصّل الهاتف وشغّل
  `adb logcat -d | grep -iE "chromium|capacitor|civildraft" | tail -200`

## ٤ · Google Play (بعد Go)
ارفع `CivilDraft-N.aab` إلى مسار «اختبارٍ داخليّ» أوّلاً، وفعّل Play App Signing.
الوصفُ والصورُ والسياسةُ الخصوصية (التطبيقُ لا يجمع بيانات؛ المساعدُ الذكيّ يتّصل
بالمزوّد الذي يختاره المستخدم بمفتاحه هو) مطلوبةٌ قبل النشر.
